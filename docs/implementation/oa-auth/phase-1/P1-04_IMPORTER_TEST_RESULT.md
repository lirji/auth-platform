# P1-04 受控拉取器 pass

本 pass PASS，P1-04 整体仍 IN_PROGRESS。同一执行者在实现后进行独立验证 pass，未使用独立代理。

## 实现行为

`DirectoryImportCli register|pull <0600-config>` 使用固定来源/环境/OA 企业/auth 企业/发行方/出口 URL/读取凭据。
来源登记为显式操作，目标企业必须已存在；运行不自动迁移数据库。URL 使用 HTTPS（回环例外），不跟随重定向；配置字符串不回显凭据。

一次最多 1000 条、每页最多 100 条，完整 HTTP 正文大小、连接/读取时间有上限；总运行在事件边界检查两分钟预算。
严格解析页/事件，拒绝序号缺页、重复 JSON 键、未知字段、错误来源与源端已确认水位领先本地检查点。
来源声称存在已提交数据却返回空页时显式失败；退出不留下后台循环。

网络操作全部位于治理事务之外。每个事件由既有 Inbox 用例独立提交，再确认连续水位；重跑先补确认本地已提交水位。
确认错误不能撤销已提交业务事实，下一次从数据库检查点恢复。冲突/网络失败均非零退出，不跳过毒消息。
