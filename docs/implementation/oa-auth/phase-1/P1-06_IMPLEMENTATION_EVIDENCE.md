## 实现与边界

LifecycleCli 从 0600 配置文件取得操作者和范围，命令文件只有命令 ID、目标、预期版本、原因。规范 UUID 企业范围只能停用本企业成员；保留 GLOBAL 范围只能停用全局主体。没有匿名 HTTP 写入口，也没有把 JWT isAdmin 当管理权。

LifecycleGovernance 在专用 TransactionTemplate 内完成命令唯一占位、摘要核对、当前状态、条件更新、追加审计与回执；事务上限沿用 5 秒，SQL 4 秒/锁 2 秒，无远程调用和 MQ 发布。相同命令并发由唯一键/命令行锁串行，不同命令通过目标版本 CAS 竞争，失败回滚。返回当前目标事实，不返回历史权限。

V2 追加审计原因、前后状态与前版本，历史记录保持兼容。V2 在隔离库执行后审查发现：全空字段的历史兼容分支还应禁止新停用操作使用，因此新增 V3 操作级必填约束，没有改写已执行 V2 或 V1。所有新增列/约束均有中文注释。

只实现 ACTIVE → SUSPENDED；成员代际不变，全局停用不改成员记录。离职、恢复、重新加入和邀请继续由相应来源/生命周期契约实施，不通过此命令暗中恢复或发权限。OA 事件尚未接入，不能声称 OA 离职已完成全平台撤权。
