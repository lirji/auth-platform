## 生产候选结论：HOLD

这不是本地开发阻塞，但以下条件没有本轮证据，不能把本轮结果外推到生产：

1. 真实OA主体与旧运营actor的逐一签核、真实目标租户/环境和资源Owner清单；测试身份不能直接复用。
2. 活跃永久来源的期限语义决定。dry-run隔离缺乏validity_decision的允许来源，不默默改成一年或无限期。动态MERCHANT后代范围仍隔离。
3. 按真实流量持续影子观察、完整增量来源和删除墓碑、管理冻结时的最终对账及在途请求耗尽；本轮为有限样本和隔离新库，并非生产观察窗口。
4. 独立DDL迁移Owner、业务账号最小DML权限、服务调用方允许列表、私有配置、备份恢复及容量目标。MySQL binlog下V48触发器需要迁移Owner权限，不得给应用账号追加SUPER或改共享log_bin_trust_function_creators。
5. 真实经营客户端/页面的SSO及租户头接入验收；本轮保留原经营API和业务用例，验证HTTP及后台链路，不宣称所有旧页面已迁移。P5已有商品查询/元资料/导出入口保持其独立能力定义。
6. 生产发布授权、P7安全/运行门禁。未部署生产，未改变共享Casdoor8000的升级HOLD。
