# 治理页面完整链路

用户已确认完整实施、正常 Git main 推送及本机 5273 更新。复用 React18、TypeScript、AntD5、React Query、Router6、现有主题和 OIDC。

## 事实、未知项与取舍

- published-catalog 已有菜单树、route、any_of、能力风险/停用/可授予状态及资源范围；无中文名称或 HTTP 动作分类，显示权威编码，不虚构字段。
- access/state 提供每页100项游标；角色不可变。跨页角色索引有数量上限、取消和循环游标防护；任何失败不返回部分关联。列表筛选明确当前页，不伪造总数。
- queryKey 绑定主体、成员代际及完整应用分区；组织切换取消请求并清缓存。
- 不迁入隔离 test 目录、不新增 Grant、不改变原有管理/业务授权边界。
- 技术选型、功能架构、影响分析 Gate PASS：复用稳定契约，不新增依赖、数据库或中间件。
