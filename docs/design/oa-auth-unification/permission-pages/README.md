# 菜单、角色与权限页面

打开 http://localhost:5273/governance，选择组织及应用后，从左侧「应用管理」进入：

- 菜单权限：树形菜单、页面路由、直接关联权限及子菜单权限。
- 权限目录：搜索、菜单/资源/风险/状态筛选，权限详情及固定角色关联。
- 角色管理：完整权限与资源、关联菜单、版本差异和授权引用；创建/复制固定版本。
- 成员授权：受益成员、固定角色版本、数据范围、有效期、来源详情及回收。

申请策略、我的权限、申请通知、授权审计与来源诊断保留，并可从上述详情跳转。页面读取当前组织/应用/环境已发布的真实目录，角色关联不等于成员已经获得访问权限。授权已受理与投影实际生效分别展示。
