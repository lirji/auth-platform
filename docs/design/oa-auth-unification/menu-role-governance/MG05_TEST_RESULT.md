- 成功原命令先于期限／当前基础检查返回原回执，新命令必须重新验证。摘要绑定服务器预览 ID；旧候选摘要算法保留，元数据逐字段比较修复缺省原因与文本“null”碰撞，未改旧历史哈希。快照／展示／指针／审计／来源保持同事务。
- CatalogEditor展示导出信封来源、差异、业务原因／授权处理决定、可选完整影响确认、固定预览ID／期限／双摘要、策略及发布结果。编辑任意发布输入使票据失效；旧服务缺功能不能降级发布；启用或发布结果未知时冻结编辑／关闭，使用原命令与原票据重试。独立影响请求在冻结／切换候选时取消，防旧响应修改固定票据。
