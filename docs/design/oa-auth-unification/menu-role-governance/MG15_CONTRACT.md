# MG15能力弃用契约（FROZEN）

2026-10-03。依赖MG05／MG12已DONE，按已批准D-RET建议冻结“先停止新增使用，历史事实保留”；不实施MG16最终退役、人员规则或生产部署。实例／数据库隔离沿用用户已明确选择的D-ENV。

## 状态与权威

能力生命周期元数据属于Auth目录模块，按application／capability持久化，缺行等价ACTIVE／version0。新增状态仅ACTIVE、DEPRECATED，带当前版本、原因、真实Owner和UTC时刻；变更及原命令结果单独追加审计。DEPRECATED不是紧急disabled，原能力定义、manifest和角色版本不改写。新版清单或旧成功发布重试不能清除生命周期元数据。

仅当前HUMAN应用Owner可以显式弃用或恢复，不能由普通分区管理权继承。Owner范围是本权限实例内该应用的所有企业／环境；页面明确这个作用域，测试／生产独立实例不互相操作。恢复同样需要新Owner命令、预期版本和原因，不自动授予、迁移、复活已撤销／失败申请或清除紧急停用。

## 新增使用矩阵

| 入口／已有事实 | DEPRECATED规则 |
|---|---|
| 新角色版本（包括复制历史版本） | 任一能力已弃用即拒绝新增角色；历史角色继续可读。 |
| 新DIRECT／GROUP／OA_REQUEST Grant及角色迁移授新 | 即使引用旧角色也拒绝创建新来源；迁移已撤旧不能为兼容而补回。 |
| 新管理委派或扩大原委派能力／期限 | 拒绝新增弃用能力的使用；纯撤销／缩减可继续，不能阻碍治理。 |
| 新申请策略、新申请 | 拒绝使用含弃用能力的角色；旧策略／申请快照保留。 |
| 尚未创建Grant的批准 | 重新核验时拒绝产生新Grant，记录真实执行失败／拒绝依据，不伪造新批准。 |
| 已存在ACTIVE或PENDING Grant | 弃用本身不撤销，原期限／范围／成员资格和实时判权继续约束；既有投影可以完成。 |
| 撤权、取消、到期／离职回收及投影重试 | 继续允许，不能把生命周期门禁施加于减少权限的路径。 |
| 已成功同命令重试 | 当前调用资格仍校验，只读取原已提交事实，不把重试解释成新增使用或延长期限；异载荷冲突。 |
| 已有访问／菜单展示／原审批历史 | 不把DEPRECATED映射为DENY或disabled，不声称现有授权已收回。 |

紧急disabled规则继续优先独立生效；本片没有最终删除或退役接口。新菜单复用历史能力不自动授予，目录发布仍完整保留能力与生命周期事实；具体项目接口引用退出门禁在MG16处理。

## 写栅栏与兼容

追加V27／V28数据库迁移，不修改已应用V26或回填历史角色／Grant。所有新增入口使用统一持久化检查；写事务先对应用目录取得共享锁再检查生命周期，Owner变更取得同一应用排他锁，明确并发提交顺序。数据库INSERT及必要的扩大UPDATE守卫覆盖角色、Grant、委派、策略和申请，旧节点不能绕过；状态回收／投影推进不被误阻断。涉及委派缩减时比较真实能力集合、代际和期限上限，不只比较JSON字符串。

新节点返回稳定CAPABILITY_DEPRECATED业务拒绝；旧节点遇到数据库守卫可以保守失败，不能返回成功掩盖失败。生产启用前必须完成迁移和写节点兼容核对，旧节点不得绕过守卫；本片不自动启用生产。历史成功命令重试不新增写入。公开目录字段追加兼容，旧请求字段和Manifest不变；旧目录响应缺少新元数据时只显示缺失，不给Owner弃用操作资格。不存在的能力、未知状态、无Owner或跨应用目标拒绝。

## HTTP与页面

沿用治理Bearer／严格JSON≤16KiB／no-store。新增`POST /api/governance/v1/catalog/capability-lifecycle`，字段application_id、capability、state、expected_version、reason、command_id；状态只接受ACTIVE／DEPRECATED，版本从0开始，响应包含当前状态／版本／原因和原命令回执。匿名401、非Owner403、非法400、版本／异命令409、依赖503；不得接受actor字段。

既有published-catalog兼容增加能力生命周期状态、版本、原因及当前Owner管理资格，view_hash纳入生命周期依据，读取前后重验；旧字段disabled、grantable不改变语义。DEPRECATED能力grantable=false，页面独立显示“已弃用 · 停止新增”，不能显示成超委派或已紧急停用。

权限目录详情提供Owner专属弃用／恢复入口，展示当前状态、原因、版本和作用域，输入变更原因并明确确认后提交。未知结果固定原对象、状态、版本、原因和命令；只提供重试原命令。普通管理者只读生命周期。弃用成功刷新真实目录和受影响选项，不能显示授权已回收。角色／授权／策略表单继续复用服务端grantable数据，直接API同样被阻断。
